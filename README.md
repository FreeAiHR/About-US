# 其它 else

除了大模型人力资源系统，我们还在持续迭代：大模型呼叫中心系统。实现智能机器人接听 400 来电，电话呼出做满意度调查、回访等等，以及企业的智能电话前台，接听来电电话。由于呼叫中心源代码有可能被不法分子利用，因此代码未全量开源，必须企业单独联系我们，经过我们审核、培训之后方可交付，因此会有相关一些费用，敬请知悉（备注：呼叫中心行业，涉及运营商线路、语音网关设备厂商、IP 电话，行业垂直 know-how 知识较多，因此进行有关培训）。
In addition to our large-scale HR system, we are also continuously iterating on our large-scale call center system. This system enables intelligent chatbots to answer 400 calls, conduct satisfaction surveys and follow-ups via outbound calls, and provides an intelligent front desk for answering incoming calls. Because the call center source code may be exploited by malicious actors, it is not fully open-source. Companies must contact us individually for review and training before delivery, which will incur associated costs. Please be aware of this. (Note: The call center industry involves extensive industry know-how regarding carrier lines, voice gateway equipment manufacturers, and IP telephony; therefore, relevant training is required.)
